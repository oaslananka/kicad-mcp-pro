# KiCad MCP Pro — Open-Source Sponsorship & Partnership Brief

**Independent project · MIT license · Corporate sponsorship opportunities · 7 November 2026**

## The project

KiCad MCP Pro bridges MCP-capable AI tools and KiCad electronics-design workflows. It supports schematic and PCB inspection, design-rule validation, BOM-oriented workflows, DFM review and manufacturing preparation. Safety-critical actions and manufacturing release remain subject to explicit permissions and human engineering review.

- Source and documentation: https://github.com/oaslananka/kicad-mcp-pro
- Project site: https://oaslananka.github.io/kicad-mcp-pro/
- Packaging: PyPI, npm wrapper and desktop installer distribution are documented in the repository. Published binary releases can lag unreleased source improvements.
- License: MIT. The project is independent and is not affiliated with, endorsed by or sponsored by any supplier named in its compatibility documentation.

## Why a company might collaborate

- **Component distributors:** document reliable component search, stock/pricing and BOM handoff through permissioned supplier APIs. No paid placement in technical recommendations.
- **PCB manufacturers/assemblers:** explore reproducible DFM and manufacturing-package preparation, traceable review feedback and educational examples.
- **Developer-tool or infrastructure providers:** help sustain code signing, build/test capacity, documentation and open engineering education.
