# KiCad MCP Cloud

> Connect AI tools to selected local KiCad project summaries without uploading entire designs to the Cloud.

## How it works

1. Sign in to your Cloud account.
2. Pair your own computer from the local Connector, with browser approval.
3. Add a compatible AI assistant using the protected HTTPS MCP endpoint.
4. Grant each AI assistant permission to read a specifically registered project.

Device pairing alone does not authorize project access. Cloud MCP currently supports read-only summaries and bounded project inspection, not remote PCB edits.
